Scratch - introdução ao código

Tempo de Aula: 1h30min

Recursos Didáticos

Projetor, quadro branco, computadores.

Metodologia

Expositiva, aplicação de exercícios / solução de problemas.

Conteúdo Programático

Como Aplicar movimentos aos personagens APlicar o bloco de comando Repita. Aplicar o bloco de comando SE Utilização dos blocos de comandos sensores. Utilizar o bloco de comando trocar fantasia Inserir o cenário do jogo/animação Salvando o projeto Projeto.

Descrição

No primeiro momento deve-se explicar o conceito do Bloco de comando repita, fazendo com que o personagem repita os movimentos até encostar na borda da tela. Logo depois dentro do bloco de comando repita, utilizar o comando trocar fantasias. Deve-se estimular os alunos a editar os personagens para simular animação, e ao mesmo tempo modificar as fantasias para dar ilusão de movimento. Após essa parte ensinar a Modificar o cenário de fundo com algum da escolha do aluno.

Avaliação

Execução dos exercícios em sala de aula.

Exercícios de Desafio

Exercício 1: Criar uma animação simples Crie um projeto onde o personagem escolhido faça pelo menos dois movimentos diferentes (exemplo: andar para frente e girar). Use blocos de código para controlar esses movimentos e troque as fantasias para simular animação.

Exercício 2: Explorar a área de fantasias e sons Adicione uma nova fantasia ao personagem ou crie uma fantasia personalizada. Depois, escolha ou grave um som e faça o personagem reproduzi-lo quando a bandeira verde for clicada.

Exercício 3: Salvar e compartilhar o projeto Salve o projeto com um nome criativo. Caso tenha acesso à internet, publique o projeto no site do Scratch e copie o link para compartilhar com um colega ou professor.
