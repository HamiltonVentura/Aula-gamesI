Construct: Tile Maps

Tempo de Aula: 1h30min

Recursos Didáticos

Projetor, quadro branco, computadores.

Metodologia

Expositiva, aplicação de exercícios / solução de problemas.

Conteúdo Programático

Criar cenários baseados em tilemaps prontos.(Fornecidos pela equipe) Trabalhar mudança de cenário.

Descrição

Ensinar ao aluno a utilizar o mosaico para criação de cenários, produzindo pelo menos dois níveis em um jogo no estilo plataforma, um portal deve levar o aluno a outro nível.

Avaliação

Execução dos exercícios em sala de aula. Modalidade: presencial.

Exercícios

Exercício 1: Criar um cenário básico com tilemap Utilize os tilemaps fornecidos para montar um cenário inicial para seu jogo. Organize os tiles para formar plataformas e obstáculos básicos.

Exercício 2: Criar múltiplos níveis Com base no cenário criado, construa pelo menos dois níveis diferentes usando tilemaps. Cada nível deve ter características distintas, como layout ou dificuldade.

Exercício 3: Implementar troca de cenário via portal Adicione um portal no primeiro nível que, ao ser ativado pelo personagem, leva o jogador para o segundo nível. Configure os eventos para que a troca de cenário ocorra de forma suave e funcional.
