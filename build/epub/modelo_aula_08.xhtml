Construct: Animação de Personagem II

Tempo de Aula: 1h30min

Recursos Didáticos

Projetor, quadro branco, computadores.

Metodologia

Expositiva, aplicação de exercícios / solução de problemas.

Conteúdo Programático

O aluno aprenderá o que é uma folha de Eventos e como utilizar as condições para animar o personagem. Especificamente animar evento de movimentos do personagem inserir entradas no layout como teclado ou mouse. Espelhamento do Personagem.

Descrição

O aluno deverá criar personagem, o chão do cenário e criar animações do personagem, correndo, parado e golpes. Cada Lista da animação deverá ser ativada caso alguma condição seja satisfeita.Por exemplo: Seta para direita foi apertado, ou barra de espaço. Nesse primeiro contato com eventos, ele deverá entender que se trata das mesmas condições que existem no Scratch, basta lembrar os alunos.

Avaliação

Execução dos exercícios em sala de aula.

Exercícios de Desafio

Desafio 1: Animação com múltiplos estados Crie animações distintas para o personagem: parado, correndo e atacando. Configure a folha de Eventos para que o personagem alterne entre essas animações conforme as teclas pressionadas (exemplo: seta para direita para correr, barra de espaço para ataque).

Desafio 2: Controle por teclado e mouse Implemente entradas para que o personagem possa ser controlado tanto pelo teclado (movimentos e ataques) quanto pelo mouse (por exemplo, clique para atacar). Certifique-se de que as animações corretas sejam ativadas para cada ação.

Desafio 3: Espelhamento do personagem Configure o personagem para que, ao andar para a esquerda, a imagem seja espelhada horizontalmente, dando a sensação de que ele está virado para o lado correto. Teste a transição entre espelhamento e animações sem causar interrupções visuais.
