Introdução ao Scratch: Variáveis

Tempo de Aula: 1h30min

Recursos Didáticos

Projetor, quadro branco, computadores.

Metodologia

Expositiva, aplicação de exercícios / solução de problemas.

Conteúdo Programático

Utilizar as estruturas básicas do Scratch para um desafio final utilizando variáveis para contar a quantidade de moedas recolhidas pelo gatinho.

Descrição

Para esse desafio final, alguns elementos são necessários para o aluno conseguir entender a lógica do construct: 1 - Condições (Bloco SE) 2 - Comparar Variáveis Para tanto será feita uma revisão para posteriormente ser lançado o desafio.

Avaliação

Execução dos exercícios em sala de aula.

Exercícios de Desafio

Desafio 1: Criar uma condição simples Utilize o bloco SE para criar um programa onde, se uma variável atingir um valor específico, uma ação seja executada (exemplo: mudar a cor de um objeto ou mostrar uma mensagem).

Desafio 2: Comparação de variáveis Programe duas variáveis para serem comparadas. Quando as variáveis forem iguais, execute uma ação (exemplo: desbloquear uma fase ou ativar um efeito).

Desafio 3: Combinação de condições e variáveis Crie um cenário onde múltiplas condições devem ser atendidas para uma ação ocorrer. Por exemplo, se variável A for maior que 10 e variável B for igual a 5, então o personagem ganha um bônus.
