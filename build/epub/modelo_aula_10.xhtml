Construct: Elementos de jogo - Barra de vida, Moedas (status)

Tempo de Aula: 1h30min

Recursos Didáticos

Projetor, quadro branco, computadores.

Metodologia

Expositiva, aplicação de exercícios / solução de problemas.

Conteúdo Programático

Criar barra de vida manualmente Criar um indicador de moedas. Conceito de Camadas

Descrição

Ensinar o aluno a Construir uma barra de vida, que demonstre a quantidade de vida que o personagem possui, lembrando que é necessário criar variáveis globais que armazenam a quantidade de vida. Ativar a camada Paralax, 0,0 para que o personagem ao se movimentar seja seguido pela quantidade de vida.

Avaliação

Execução dos exercícios em sala de aula.
