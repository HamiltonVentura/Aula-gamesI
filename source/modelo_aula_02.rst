Introdução ao Scratch, navegação e criação de projeto
=====================================================

**Tempo de Aula:** 1h30min

.. rubric:: Recursos Didáticos

Projetor, quadro branco, computadores e internet.

.. rubric:: Metodologia

Expositiva, aplicação de exercícios e solução de problemas.

.. rubric:: Conteúdo Programático

- Ligar computador, abrir navegador web, pesquisar no Google.
- Iniciar um projeto no Scratch; navegar nas áreas: código, área de trabalho, fantasias, sons.
- Iniciar desenhando ou alterando personagens.
- Salvar projeto.

.. rubric:: Descrição

Ministrar sobre o que o Scratch pode fazer, seus objetivos como ferramenta de
programação, desenvolvimento de animações e jogos.

Em segundo lugar, deve-se orientar os alunos a como ligarem os computadores,
acessarem os navegadores e fazer a pesquisa para achar a plataforma — alguns alunos não sabem.

Após esse primeiro contato, explica-se as partes de cada tela. Em seguida, os alunos devem
executar simultaneamente conforme o professor explica, clicando em cada parte da tela.

A parte lúdica dessa primeira aula é deixar os momentos finais para eles brincarem
com os personagens.

.. rubric:: Avaliação

Execução dos exercícios em sala de aula.


Desafios - Introdução ao Scratch, navegação e criação de projeto
---------------------------------------------------------------

**Exercício 1: Criar uma animação simples**  
Crie um projeto onde o personagem escolhido faça pelo menos dois movimentos diferentes (exemplo: andar para frente e girar).  
Use blocos de código para controlar esses movimentos e troque as fantasias para simular animação.  

**Exercício 2: Explorar a área de fantasias e sons**  
Adicione uma nova fantasia ao personagem ou crie uma fantasia personalizada.  
Depois, escolha ou grave um som e faça o personagem reproduzi-lo quando a bandeira verde for clicada.  

**Exercício 3: Salvar e compartilhar o projeto**  
Salve o projeto com um nome criativo.  
Caso tenha acesso à internet, publique o projeto no site do Scratch e copie o link para compartilhar com um colega ou professor.
